Introduction

ce mini-site a été créer dans le cadre du cours de TP Programmation web.

Il permet de découvrir la création de plusiers pages HTML reliées entre elles.

Objectifs du mini-site

L'objectifs est d'apprendre à structurer un petit projet web avec plusieurs fichiers.

Pages disponibles

  • la page d'acceuil présente le contexte général du mini-site.
  • la page Présentation contient les informations personnelles de l'étudiant
  • La page contact contient les informations de contact de l'étudiant
